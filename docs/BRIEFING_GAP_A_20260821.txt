## GAP A2: RÜCKBLICK — MOND-STATISTIK + TEILEN (Plan A2)

### web/src/pages/rueckblick.astro
1. **Mond-Statistik** (client-seitig, keine Dependencies):
   - Funktion ergänzen:
     ```js
     function moonPhase(date) {
       var knownNewMoon = Date.UTC(2000, 0, 6, 18, 14);
       var synodic = 29.53058867 * 86400000;
       var diff = date.getTime() - knownNewMoon;
       return ((diff % synodic) + synodic) % synodic / synodic;
     }
     function moonLabel(phase) {
       if (phase < 0.0625 || phase >= 0.9375) return "NEUMOND";
       if (phase >= 0.4375 && phase < 0.5625) return "VOLLMOND";
       if (phase >= 0.1875 && phase < 0.3125) return "ERSTES VIERTEL";
       if (phase >= 0.6875 && phase < 0.8125) return "LETZTES VIERTEL";
       return phase < 0.5 ? "ZUNEHMEND" : "ABNEHMEND";
     }
     ```
   - In der Jahres-Aggregation: Für jeden Fang moonLabel(moonPhase(new Date(c.catch_ts))) zählen; zusätzlich 4 Zähl-Buckets für die Hauptphasen (NEUMOND, VOLLMOND, ERSTES VIERTEL, LETZTES VIERTEL).
   - Neue KPI-Karte **MOND** in der KPI-Zeile: häufigste Hauptphase (z.B. „VOLLMOND") mit kleinem Icon (☾ als Text, KEIN SVG nötig — Design-Regel: keine SVG-Icons, minimalistisch).
   - Kleine Verteilungs-Balken (4 schmale divs, gleiche Optik wie Monats-Balken): NEUMOND / ERSTES VIERTEL / VOLLMOND / LETZTES VIERTEL mit relativer Höhe (height: %), Labels darunter.
2. **Teilen-Button**:
