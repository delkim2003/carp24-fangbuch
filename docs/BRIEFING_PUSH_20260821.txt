## MIGRATION (NEU): /mnt/projekte/carp24-fangbuch/supabase/migrations/0025_push_subscriptions.sql
```sql
-- 0025_push_subscriptions.sql — Web-Push (E2)
CREATE TABLE IF NOT EXISTS public.push_subscriptions (
  user_id uuid NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  endpoint text PRIMARY KEY,
  keys jsonb NOT NULL,               -- { p256dh, auth }
  created_at timestamptz NOT NULL DEFAULT now()
);
ALTER TABLE public.push_subscriptions ENABLE ROW LEVEL SECURITY;
CREATE POLICY "push_subscriptions_own" ON public.push_subscriptions FOR ALL TO authenticated USING (user_id = auth.uid()) WITH CHECK (user_id = auth.uid());
GRANT SELECT, INSERT, DELETE ON public.push_subscriptions TO authenticated;
-- FK zu profiles für PostgREST-Relation falls nötig
ALTER TABLE public.push_subscriptions DROP CONSTRAINT IF EXISTS push_subscriptions_user_profiles_fk;
ALTER TABLE public.push_subscriptions ADD CONSTRAINT push_subscriptions_user_profiles_fk FOREIGN KEY (user_id) REFERENCES public.profiles(id) ON DELETE CASCADE;
```

## API-ROUTE (NEU): /mnt/projekte/carp24-fangbuch/web/src/pages/api/push/subscribe.ts
Astro-Server-Route (export const POST, prerender=false, Muster wie /api/stripe/checkout.ts).
- Auth: Session via Cookies → 401 ohne User.
- Body: { endpoint, keys: { p256dh, auth } } → insert in push_subscriptions (via Server-Supabase-Client aus supabase-client.ts; upsert auf endpoint: `.upsert({ user_id, endpoint, keys }, { onConflict: "endpoint" })`).
- Return 200 { ok: true }.
- Zusätzlich POST /api/push/send (gleiche Datei export const POST? Nein — getrennt: Datei send.ts): Auth-User → findet eigene Subscriptions → web-push sendet Test-Notification "Carp24: Push aktiv!" → 200. Wenn VAPID_PRIVATE_KEY fehlt → 503.

## PROFIL (EDIT): /mnt/projekte/carp24-fangbuch/web/src/pages/profil.astro
