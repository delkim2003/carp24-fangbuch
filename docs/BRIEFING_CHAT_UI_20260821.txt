## DATEI (NEU): /mnt/projekte/carp24-fangbuch/web/src/pages/chat.astro
- SSR-Auth-Guard (Session, Redirect /login/). Kicker "PASSION. FISHING. COMMUNITY.", H1 "CHAT". M3-Tokens, Dark-Mode-fähig.
- **Historien laden:** `supabase.from("chat_messages").select("*, profiles(display_name)").order("created_at", { ascending: true }).limit(100)` (letzte 100 — wenn mehr, einfach 100 neueste). Client-seitig rendern (JS-Funktion renderMessages(list)).
- **Realtime-Subscription** (client-seitig, nach Session):
```js
const channel = supabase.channel("chat-main")
  .on("postgres_changes", { event: "INSERT", schema: "public", table: "chat_messages" }, (payload) => {
    // payload.new: id, user_id, body, created_at — display_name fehlt hier!
    // display_name lazy-laden: aus profiles (einmalige Map user_id -> display_name aufbauen beim Laden + für neue User nachladen)
    renderMessage(payload.new);
  })
  .subscribe();
```
- **WICHTIG Realtime + display_name:** Beim INSERT-Event hat payload.new KEIN profiles-Join. Baue eine `nameMap` (user_id → display_name): beim Historien-Laden befüllen; für unbekannte user_id eine kleine Query `supabase.from("profiles").select("id, display_name").in("id", [unbekannteIds])` nachladen. Fallback "Angler".
- **Senden:** Input (min-h-12) + Button "SENDEN" (min-h-12). Flood-Schutz: mindestens 2 Sekunden zwischen zwei Nachrichten (letzteSendAt-Timestamp; sonst Hinweis "Bitte kurz warten…"). Insert: `supabase.from("chat_messages").insert({ user_id: user.id, body })` — KEIN display_name senden. Nach Erfolg Input leeren; Fehler rot.
- **MELDEN:** Auf jeder eigenen/fremden Nachricht (klein, sekundär): klicken → Inline-Textarea (Grund) + "Meldung senden" → `supabase.from("content_reports").insert({ target_type: "chat_message", target_id: id, reporter_id: user.id, reason })` → "Meldung gesendet". 
- **LÖSCHEN:** nur eigene Nachrichten (user_id === user.id): Lösch-Button (bestätigen) → DELETE (RLS own).
- **Layout:** Nachrichten-Liste (max-h-[60vh] overflow-y-auto, älteste oben), eigene rechts/anders gefärbt (primary-surface), fremde links. Zeit formatieren (de-DE, HH:mm). Auto-Scroll zuletzt.
