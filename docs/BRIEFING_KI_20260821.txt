## API-ROUTE (NEU): /mnt/projekte/carp24-fangbuch/web/src/pages/api/ai/chat.ts
Astro-Server-Route (POST, prerender=false, Muster /api/stripe/checkout.ts).
- Auth: Session via Cookies → 401.
- Body: { message: string } — max 500 Zeichen (sonst 400).
- Rate-Limit: in-memory Map userId → letzter Request-Timestamp; <10s → 429 { error: "Bitte kurz warten." }.
- Wenn OPENROUTER_API_KEY fehlt → 503 { error: "KI ist noch nicht konfiguriert." }.
- Kontext: Lade die letzten 20 eigenen Fänge (Server-Client aus supabase-client.ts, `.eq("user_id", user.id).is("deleted_at", null).order("catch_ts", { ascending: false }).limit(20)`) — kompakt als Kontext-String (Datum, kg, Art, Gewässer).
- Prompt an OpenRouter (fetch POST https://openrouter.ai/api/v1/chat/completions, Header Authorization Bearer + HTTP-Referer/Title optional):
  System: "Du bist der CARP24 Angelassistent. Antworte kurz (max 150 Wörter), sachlich, auf Deutsch (oder in der Sprache der Frage). Nutze nur den gegebenen Fang-Kontext — erfinde nichts."
  User: Kontext + Frage.
- Model: "deepseek/deepseek-chat-v3-0324" (oder "openrouter/auto") — nimm "deepseek/deepseek-chat-v3-0324", fallback "openrouter/auto".
- Timeout: AbortController 30s. Bei Fehler → 502 { error: "KI-Dienst nicht erreichbar." }.
- Response: { answer: string } (content aus choices[0].message.content).
- KEIN Logging von Prompt/Response. Kommentar: "DSGVO: transiente Verarbeitung, keine Speicherung, kein Logging."
