## DATEI 2: /mnt/projekte/carp24-fangbuch/web/src/layouts/Layout.astro
1. Im <head> VOR dem Stylesheet-Link ein Inline-Script (verhindert Flash):
```html
<script is:inline>
  (function () {
    var t = localStorage.getItem("carp24-theme");
    if (t === "dark" || (!t && window.matchMedia("(prefers-color-scheme: dark)").matches)) {
      document.documentElement.setAttribute("data-theme", "dark");
    }
  })();
</script>
```
2. In der Navigation (dort wo die anderen Nav-Buttons sind) einen Theme-Toggle-Button ergänzen — Icon-frei, Text-Variante im bestehenden Stil (font-nav-item uppercase, min-h-11 wie Chips):
```html
<button id="theme-toggle" type="button" class="...bestehende Chip-Optik..." aria-label="Design wechseln">THEMA</button>
```
3. Am Ende (vor </body> oder im bestehenden Script-Bereich) das Toggle-Script (is:inline):
```html
<script is:inline>
  var toggle = document.getElementById("theme-toggle");
  if (toggle) {
    toggle.addEventListener("click", function () {
      var html = document.documentElement;
      var dark = html.getAttribute("data-theme") === "dark";
      html.setAttribute("data-theme", dark ? "" : "dark");
      localStorage.setItem("carp24-theme", dark ? "light" : "dark");
    });
  }
</script>
```
Achtung: Beim Toggle auf light das data-theme-Attribut ENTFERNEN (html.removeAttribute), nicht auf "" setzen, damit der prefers-color-scheme-Fallback stimmt. Nutze removeAttribute.
