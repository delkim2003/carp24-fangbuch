ALTER TABLE public.profiles ADD COLUMN IF NOT EXISTS ban_reason text;

CREATE TABLE IF NOT EXISTS public.admin_audit_log (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  actor_id uuid NOT NULL REFERENCES public.profiles(id) ON DELETE SET NULL,
  action text NOT NULL,
  target_type text,
  target_id text,
  details jsonb,
  created_at timestamptz NOT NULL DEFAULT now()
);

## API-ERWEITERUNGEN

### 1. /api/admin/users.ts (erweitern — Datei VOLLSTÄNDIG überschreiben)
- **GET**: Parameter q (Suche display_name/email, ILIKE), role, pro (true/false), banned (true/false/alle), limit 200. Response pro User zusätzlich: banned_at, ban_reason, open_reports_count (Anzahl content_reports status=open mit target_id in dessen Inhalten ODER reporter_id = user — einfacher: count content_reports where reporter_id = user AND status='open'). Sortierung: created_at desc.
- **PATCH**: Body kann enthalten: role, is_pro, ban (bool + reason), unban (bool).
  - ban=true: UPDATE profiles SET banned_at=now(), ban_reason=? WHERE id=?; ZUSÄTZLICH supabaseAdmin.auth.admin.updateUserById(user_id, { ban_duration: "876000h" }) — blockt echten Login
  - unban=true: UPDATE profiles SET banned_at=NULL, ban_reason=NULL; + supabaseAdmin.auth.admin.updateUserById(user_id, { ban_duration: "none" })
  - Jede Änderung → admin_audit_log insert (action: 'user.role'/'user.pro'/'user.ban'/'user.unban', target_type:'user', target_id, details:{field, from, to})
- **POST {action:"reset_password", id}**: supabaseAdmin.auth.admin.updateUserById(id, {password: generiertes 12-Zeichen-Passwort (crypto.randomBytes(6).toString('hex') + "Aa1!")}) → Response {password} (NUR einmal anzeigen); audit_log 'user.reset_password'
- **DELETE** (soft delete wie bisher) + audit_log 'user.delete'
