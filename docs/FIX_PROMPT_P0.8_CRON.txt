Fix Cron-Symlink-Bug in /mnt/projekte/carp24-fangbuch/infra/backup.sh (carp24).

PROBLEM: Der Cron carp24-backup-daily referenziert /home/philipp/.hermes/profiles/agentur-berater/scripts/carp24-backup.sh (Symlink auf infra/backup.sh). Beim Aufruf ueber den Symlink zeigt dirname "$0" auf das scripts/-Verzeichnis statt auf infra/ → SCRIPT_DIR falsch → .env und backups werden am falschen Ort gesucht → FEHLER: .env nicht gefunden, BACKUP_DIR nicht gesetzt. Das taegliche Backup wuerde UM 02:30 FEHLSCHLAGEN.

FIX: SCRIPT_DIR und REPO_ROOT mit realpath aufloesen (loest Symlinks auf):
AKTUELL (Z.11-12):
  SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"
  REPO_ROOT="$(cd "$SCRIPT_DIR/.." && pwd)"
FIX:
  SCRIPT_DIR="$(cd "$(dirname "$(readlink -f "$0")")" && pwd)"
  REPO_ROOT="$(cd "$SCRIPT_DIR/.." && pwd)"

(readlink -f loest den Symlink auf die echte Datei in infra/ auf → SCRIPT_DIR wird infra/, .env und backups werden korrekt gefunden, egal ob direkt oder ueber Symlink aufgerufen.)
