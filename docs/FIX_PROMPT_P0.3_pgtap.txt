Fix 2 identische SQL-Syntaxfehler in tests/pgtap/0001_rls_tests.sql (Postgres 17).

PROBLEM: Zwei Testfälle nutzen ein UPDATE mit RETURNING direkt in einer SELECT is(...)-Subquery:
```sql
SELECT is(
  (UPDATE public.catches SET bait = 'hacked'
   WHERE ...
   RETURNING id),
  NULL, ...
);
```
Postgres erlaubt KEIN UPDATE als Subquery — das muss ein SELECT-Wrapper sein:
```sql
SELECT is(
  (SELECT id FROM (UPDATE public.catches SET bait = 'hacked'
   WHERE ...
   RETURNING id) AS upd),
  NULL, ...
);
```
