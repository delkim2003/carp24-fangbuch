BAUE SOFORT — KEINE ANALYSE. Zwei präzise Fixes in ZWEI Dateien.

## KONTEXT
Der Storage-Bucket 'catch-photos' ist jetzt angelegt (privat, public=false) mit RLS-Policies: Upload/Select/Update/Delete nur für eigene Fotos, Pfad-Konvention = {user_id}/{uuid}.jpg. Der bisherige Client-Code lädt auf einen falschen Pfad (kein user_id-Ordner → Policy blockt), speichert eine publicUrl (funktioniert nicht bei privatem Bucket) und strippt kein EXIF-GPS (DSGVO-Standort-Leak). Fix beides.

## DATEI 1: /mnt/projekte/carp24-fangbuch/web/src/pages/fang-erfassen.astro
Ersetze den kompletten Foto-Upload-Block (ca. Zeile 485-505, beginnt bei "var file = this.files[0];" und endet bei "photosInput.value = JSON.stringify([uploadedPhotoUrl]);" mit geschlossener Klammer des .then) durch:

```html
var file = this.files[0];
    photoName.textContent = file.name;
    photoName.classList.remove('hidden');

    var sb = getSupabase();
    if (!sb) {
      showSubmitError('Foto-Upload nicht möglich — offline. Foto wird beim Sync hochgeladen.');
      return;
    }
    sb.auth.getUser().then(function (ur) {
      var userId = ur.data && ur.data.user ? ur.data.user.id : null;
      if (!userId) {
        showSubmitError('Foto-Upload fehlgeschlagen: nicht angemeldet.');
        return;
      }
      // EXIF-GPS-Strip (DSGVO): Bild via Canvas neu encodieren → Metadaten (inkl. GPS) verworfen
      var img = new Image();
      var objUrl = URL.createObjectURL(file);
      img.onload = function () {
        var maxDim = 1600;
        var scale = Math.min(1, maxDim / Math.max(img.width, img.height));
        var canvas = document.createElement('canvas');
        canvas.width = Math.round(img.width * scale);
        canvas.height = Math.round(img.height * scale);
        var ctx = canvas.getContext('2d');
        ctx.drawImage(img, 0, 0, canvas.width, canvas.height);
        URL.revokeObjectURL(objUrl);
        canvas.toBlob(function (blob) {
          var filePath = userId + '/' + crypto.randomUUID() + '.jpg';
          sb.storage.from('catch-photos').upload(filePath, blob, { contentType: 'image/jpeg' }).then(function (res) {
            if (res.error) {
              showSubmitError('Foto-Upload fehlgeschlagen: ' + res.error.message);
              return;
            }
            // Speichere Storage-PFAD (nicht publicUrl) — private Buckets brauchen signierte URLs zur Anzeige
            photosInput.value = JSON.stringify(['foto:' + filePath]);
            photoName.textContent = file.name + ' (EXIF entfernt)';
          });
        }, 'image/jpeg', 0.85);
      };
      img.onerror = function () {
        URL.revokeObjectURL(objUrl);
        showSubmitError('Foto konnte nicht gelesen werden.');
      };
      img.src = objUrl;
    });
```

WICHTIG: Prüfe danach, ob es im übrigen Script eine Variable `uploadedPhotoUrl` gibt, die noch referenziert wird (z.B. in buildInputData oder beim Sync) — wenn ja, ENTFERNE die Referenzen bzw. ersetze sie durch das photosInput-Value (JSON mit 'foto:pfad'). Das photos-Feld des Fang-Objekts muss am Ende den 'foto:pfad'-String enthalten, NICHT uploadedPhotoUrl.
