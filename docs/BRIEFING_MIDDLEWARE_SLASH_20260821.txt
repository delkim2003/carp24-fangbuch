## PROBLEM
web/src/middleware.ts leitet bei aktivem Wartungsmodus auch /login/ und /impressum/ (mit TRAILING SLASH) fälschlich auf /wartung um. Ursache: `context.url.pathname` liefert z.B. "/login/" (mit Slash), aber die isAllowed-Liste enthält "/login" (ohne Slash) → Match schlägt fehl.

## FIX (genau 1 Stelle in web/src/middleware.ts)
Ersetze in der Middleware diese Zeile:
```ts
  const path = context.url.pathname;
```
durch:
```ts
  const path = context.url.pathname.replace(/\/+$/, "") || "/";
```
NICHTS anderes ändern. Die Datei VOLLSTÄNDIG mit dem bisherigen Inhalt + dieser einen Änderung neu schreiben (No-Fragment-Regel).
