### 2. Icons erzeugen (PNG 192/512 + maskable 512)
Nutze das bestehende Branding von web/public/favicon.svg. Erzeuge die PNGs mit Python (Pillow ist verfügbar) — zeichne ein einfaches, sauberes Carp24-Icon im Editorial-Stil:
- Hintergrund: solide #0B0C0B (dunkel)
- Motiv: stilisierter weißer/heller Fisch-Haken oder „C24"-Monogramm in #E2DECC — MINIMALISTISCH, KEINE SVG-Emojis, keine Verläufe
- Für maskable: Motiv zentriert mit 40% Sicherheitsabstand zum Rand (maskable-safe zone)
- Ausgabe: web/public/icons/icon-192.png, icon-512.png, icon-maskable-512.png

Falls Pillow nicht verfügbar ist: installiere es NICHT global — nutze ImageMagick (`convert`), falls vorhanden; sonst melde es.

### 3. web/src/layouts/Layout.astro — Meta-Links ergänzen
Ergänze im <head> (vor dem CSP-Meta, nach den bestehenden Meta-Tags):
```html
<link rel="manifest" href="/manifest.webmanifest" />
<meta name="theme-color" content="#0B0C0B" />
<link rel="apple-touch-icon" href="/icons/icon-192.png" />
<meta name="mobile-web-app-capable" content="yes" />
<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent" />
```
NICHTS anderes am Layout ändern.
