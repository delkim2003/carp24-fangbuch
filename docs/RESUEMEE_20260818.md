## 🐛 Lessons Learned (18.08.)
1. **mail() auf IONOS = NICHT zuverlässig** — Zoho blockt still. Immer Zoho-SMTP direkt nutzen.
2. **`docker compose down -v` löscht keine Bind-Mount-Volumes** (`./volumes/db/data` bleibt!) → bei Passwortwechsel DB-Ordner manuell löschen.
3. **Supabase-Secrets NIE manuell raten** — offizielles `utils/generate-keys.sh --update-env` nutzen (Key-Längen exakt).
4. **Dashboard: zuerst Muster checken** (extras.json für Quick-Links, sprints[]-Array, .card-project) — nicht HTML reinklatschen.
5. **Browser-Tests: headless Playwright, nie den Desktop-Chrome** (hängt + CPU + 77°C).
6. **docker compose up -d --wait** = offizieller Start (wartet auf healthy, besser als manuelles Warten).
